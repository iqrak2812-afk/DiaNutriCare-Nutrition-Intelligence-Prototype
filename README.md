# DiaNutriCare – Culturally Adapted Diabetes Nutrition Database MVP

## Overview

DiaNutriCare is an independent Digital Health project exploring a culturally adapted nutrition support platform for South Asian communities living with diabetes.

The project focuses on developing a structured nutrition database that can support future digital health applications for dietary tracking, personalized nutrition insights, and diabetes self-management.

## Current Project Stage

Version 1 MVP – Nutrition Data Layer

The first prototype focuses on creating a clean and documented food composition database containing commonly consumed South Asian foods.

## Objectives

- Develop a structured nutrition dataset for South Asian dietary patterns.
- Collect standardized nutritional values using reliable food composition sources.
- Create a foundation for future nutrition analytics and digital health applications.

## Current Dataset

Version 1 contains:

- 10 representative food items
- Food categories
- Serving size information
- Calories
- Macronutrients:
  - Carbohydrates
  - Protein
  - Fat
  - Fibre
  - Sugar

## Data Sources

Nutrition information is collected from validated food composition databases, primarily:

- USDA FoodData Central
